# Volans 产品需求文档（PRD）

> 版本：v0.1 · 状态：草稿 · 协议：AGPL-3.0

## 1. 项目概述

Volans 是一个**自托管的可视化代理部署管理面板**，用于在一台服务器上部署、配置并运营基于 [Xray-core](https://github.com/XTLS/Xray-core) 的正向代理服务。面板提供现代化的 Web 界面，通过图形化方式管理 Xray 内核、入站节点、订阅用户与流量统计，无需手工编辑 JSON 配置。

### 1.1 定位与目标

- **定位**：单机优先、面向个人与小型团队的 Xray 部署运营面板，对标并差异化于 X-UI / 3X-UI 家族。
- **差异化**：
  - 更现代的 UI 与交互（Arco Design，极简商务风）；
  - 更清晰的代码架构，便于社区贡献与二次开发；
  - 聚焦「部署管理」与「机场式订阅用户」两大核心场景。

### 1.2 目标用户

- 需要快速自建代理服务的个人开发者；
- 需要向多用户分发代理（机场式）的小型运营者；
- 希望对 Xray 部署过程可视化的运维人员。

## 2. 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Go + Gin + SQLite（默认），预留 MySQL 扩展位 |
| 前端 | Vue 3 + TypeScript + Vite + Arco Design + Pinia |
| 图表 | ECharts |
| 通信 | REST + WebSocket（实时流量/日志推送） |
| 内核 | Xray-core（原生二进制，面板管理进程生命周期） |
| 部署 | 单二进制 + Docker + Ubuntu/Debian 一键脚本 |
| 协议 | AGPL-3.0 |

## 3. 功能需求

> 标记说明：`[MVP]` 首版实现，`[二期]` 后续版本。

### 3.1 面板认证与安全

| 编号 | 功能 | 说明 | 阶段 |
|---|---|---|---|
| A-1 | 管理员登录 | 单管理员账号（用户名 + 密码），JWT 会话 | MVP |
| A-2 | 登录失败锁定 | 连续失败 N 次后锁定 IP/账号一段时间 | MVP |
| A-3 | 面板 HTTPS | 面板自身支持 TLS | MVP |
| A-4 | 文件权限隔离 | Xray 配置与密钥文件权限收紧 | MVP |
| A-5 | 多管理员 + RBAC | 角色权限管理 | 二期 |
| A-6 | 2FA | 双因素认证 | 二期 |

### 3.2 节点 / 内核管理

| 编号 | 功能 | 说明 | 阶段 |
|---|---|---|---|
| N-1 | 内核检测 | 检测本机是否已安装 Xray 及版本 | MVP |
| N-2 | 一键安装/升级 | 下载官方 Xray 二进制，管理版本 | MVP |
| N-3 | 进程控制 | 启动/停止/重启，systemd 管理 | MVP |
| N-4 | 系统监控 | CPU/内存/磁盘/负载展示 | MVP |
| N-5 | 多服务器管理 | 远程 SSH 部署与集中管理 | 二期 |

### 3.3 入站配置

| 编号 | 功能 | 说明 | 阶段 |
|---|---|---|---|
| I-1 | 入站增删改查 | 可视化管理 inbound | MVP |
| I-2 | 协议 | VLESS + WS + TLS（首版），接口预留扩展 | MVP |
| I-3 | 传输层 | TCP/WS/gRPC/H2/QUIC/mKCP 扩展 | 二期 |
| I-4 | 配置热重载 | 面板生成 JSON 后热加载，无需重启 | MVP |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 面板自身资源占用低（< 50MB 内存），流量统计不影响转发性能 |
| 可靠性 | 面板崩溃不影响 Xray 转发（进程解耦） |
| 安全 | 密钥不落明文日志；默认仅监听本机，公网暴露需显式配置 |
| 可移植 | 单二进制跨平台（linux/amd64 优先，darwin/windows 次之） |
| 国际化 | 中/英双语 |
| 主题 | 暗色默认 + 亮色，极简商务风 |

## 5. 明确排除（当前版本不做）

- 多服务器集中管理（SSH 远程）
- RBAC 多角色、2FA
- ACME 自动证书（MVP 手动填证书）
- 旧面板（X-UI/3X-UI）数据迁移导入
- Sing-box 订阅格式
- MySQL/Postgres 持久化
- 面板自我更新（`x update`）
- 并发设备数硬限制（先技术验证）

## 6. 里程碑（Roadmap）

| 阶段 | 目标 |
|---|---|
| M0 | 项目骨架：目录、Go module、Vue 工程、README/CI |
| M1（MVP） | 登录 + 内核管理 + 入站配置 + 订阅用户 + 统计 + 订阅导出 |
| M2 | 并发设备限制、ACME、多管理员/RBAC、告警 |
| M3 | 多服务器、迁移导入、Sing-box、自我更新 |

## 7. 成功标准（MVP 验收）

1. 全新 Ubuntu/Debian 机器可通过一键脚本安装面板并启动 Xray；
2. 无需 SSH，纯 Web 界面完成「装内核 → 建入站 → 建用户 → 发订阅」全流程；
3. 用户流量达上限后自动断流，前端可见实时流量；
4. 面板重启后配置与数据不丢失（SQLite 持久化）。
