轻松部署与运营你的 Xray 正向代理 服务

Volans 是专为极简运维打造的开源可视化代理控制台。只需点几下鼠标，即可把一台普通服务器变成安全、稳定、可随时分发订阅的节点集群。

快速开始 查看 GitHub
一键快速安装命令
$ curl -fsSL https://raw.githubusercontent.com/HYuCN666/volans/main/install.sh | bash
CAPABILITIES

为现代代理运维而生的全部特性

抛弃繁琐难懂的 JSON 配置文件，享受开箱即用、安全透明的全新管理体验。

可视化内核管理

图形化管理 Xray 核心运行状态，零门槛配置 VLESS 协议、监听端口、TCP 及 WebSocket 传输流。

订阅用户与配额管理

支持创建独立订阅客户，精细分配总流量配额、上下行独立限速，以及设置自定义到期时间。

实时流量监控

内置 WebSocket 双向低延迟通信，即时推送每秒上/下行网络吞吐速率及历史流量曲线。

通用订阅一键导出

自动生成标准订阅 Token 与客户端连接，一键复制直连，主流客户端无缝即刻接入。

安全默认设计

内置 TLS 传输加密与域名嗅探 (Sniffing) 防护，严格的 JWT 身份鉴权与密码哈希保护。

现代极简控制台

对标 Vercel / Grafana 设计哲学，支持无缝亮暗色切换，低饱和度科技美学，极致专注操作。

GETTING STARTED

三步完成部署上线

支持主流 Linux 发行版，单二进制独立运行，无需复杂的第三方运行环境。

01. 下载二进制

一键下载发行版

从 GitHub Releases 获取对应架构的预编译二进制执行文件并赋予运行权限：

curl -L -o volans.tar.gz https://github.com/HYuCN666/volans/releases/latest/download/volans-linux-amd64.tar.gz tar -xzf volans.tar.gz -C /opt ln -s /opt/volans/volans /usr/local/bin/volans
02. 配置守护进程

Systemd 后台托管

配置为系统级服务，实现开机自启、崩溃自动重启与标准化日志捕获：

curl -fsSL https://raw.githubusercontent.com/HYuCN666/volans/main/install.sh | bash
03. 访问控制台

打开浏览器初始化

在浏览器中输入服务器公网 IP，登录默认管理员账号并开启您的第一个节点：

http://<your-server-ip>:8080 默认账号: admin / admin
